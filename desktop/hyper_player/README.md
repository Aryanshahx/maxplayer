# Hyper Player - All Formats: Windows preview
Separate Flutter desktop app; does not modify the Android app or its version.

## First build
GitHub -> Actions -> Windows desktop preview -> Run workflow.
Download the artifact when all checks pass. Extract BOTH ZIP layers fully into
a folder, then run hyper_player.exe. Keep all DLLs and the data folder next to it.
Do not run from inside the ZIP. Initial target: Windows 10/11 x64.

Open files (Ctrl+O), open a folder (direct children only), or add an HTTP(S)
media URL (Ctrl+L). Playlist entries persist on this computer. The player provides
its media_kit desktop transport controls, fullscreen and volume controls.
A webpage URL is not necessarily a playable media URL. DRM services are not supported.

## Privacy and limits
No Android Firebase, advertising, push, analytics, vault or Whisper integration.
Local files are not uploaded by this app. Opening online media contacts its host;
that host may log your IP and requests. Playlist paths and URLs are saved locally
using SharedPreferences (not encrypted). Avoid saving private signed URLs;
Clear playlist removes the saved entries. Other computers cannot use your local paths.
No recursive whole-disk indexing. Folder importing is not an IPTV M3U parser.
No promise of every possible format despite the product name.
UI is English in this initial preview. Other desktop features and translations
remain future work. Android remains MaxPlayer, unchanged.

## Verification status
Source prepared in a Linux environment without a usable Flutter SDK.
Windows compilation, automated tests and real playback are NOT yet verified.
The workflow must succeed and a human must test the extracted app on Windows.
Test local audio/video, streams, next-item playback, missing files, persistence,
keyboard controls, fullscreen, audio devices and clean application exit.
This ZIP is an unsigned TEST application, not a Microsoft Store EXE/MSI installer.
Store work still includes installer generation/silent install testing, trusted
code signing, immutable version-specific HTTPS hosting, licensing notices,
privacy policy, screenshots and certification. Do not submit this ZIP as an EXE.
The Windows runner is generated by Flutter in CI, including its current
Windows version/resource defaults. Set final product metadata before packaging.
